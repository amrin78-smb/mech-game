# Kimi 3D Make prompts: Scrap Titan (Unity 2.5D)

Each file is one model. Paste everything between the two lines under "Prompt to paste into Kimi 3D Make" into Kimi, one model at a time. Each prompt is complete on its own, so the shared style and technical rules repeat in every file on purpose.

Order: make the Phase 1-2 models first; the game can be played with simple placeholders until the rest arrive.
